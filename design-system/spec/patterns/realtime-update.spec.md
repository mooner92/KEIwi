# 패턴: 실시간 갱신 (Realtime Update)

> **Phase 1.** 자동 갱신·신선도 표기·`aria-live` 정책·Grafana 임베드 갱신/테마 동기화를 고정. [[principles]] 원칙7(신뢰=정확·신선) AC7.3·AC7.4 핵심.

## 목적
관측 콘솔의 신뢰는 **최신·정확**(원칙 7). 값이 언제 것인지 드러내고, 갱신을 과하지 않게 알리며, 보조기기·모션 민감 사용자를 배려한다.

## 구성 요소
1. **신선도 표기:** "마지막 갱신 hh:mm:ss" + 갱신 주기. 값 옆/영역 헤더.
2. **자동 갱신:** 주기적 재페치(데이터 종류별 주기). 수동 새로고침 + 일시정지(선택).
3. **상태:** `live`(갱신 중) / `paused` / `stale`(갱신 실패·지연 → 경고색·"지연됨").
4. **로딩:** 최초 스켈레톤, 갱신 시 기존 값 유지(깜빡임 금지).

## 갱신 메커니즘
| 데이터 | 방식 | 주기(기본) |
|---|---|---|
| 플릿 상태(strip) | 서버 컴포넌트(force-dynamic) 재요청 / 클라 폴링 | 15~30s |
| Stat/헬스 값 | 클라 폴링(fetch) 또는 라우트 재검증 | 15~30s |
| **시계열(Grafana)** | **iframe kiosk 자체 자동 새로고침** | Grafana 설정(콘솔 미관여) |

- M1은 **폴링** 기본(SSE/WebSocket은 M2+ 로그 스트리밍에서 평가 — 헌장 §6 지루한 기술). 주기는 env/상수로.
- **#2 드릴다운:** `/overview?node=…` 내비게이션 → 서버 재렌더 → 임베드 src 갱신(현행 유지, 불가침).

## 접근성 — aria-live 정책
- 갱신 영역은 **`aria-live="polite"`**(절대 `assertive` 아님 — 과낭독 금지). `aria-atomic`은 작은 단위만.
- **과도한 알림 억제:** 매 폴링마다 낭독 금지 — **의미 변화 시에만**(예: up→down) 알림. 단순 수치 미세변화는 silent.
- 상태 전이(정상→다운)는 텍스트로 노출(색+아이콘+텍스트, [[server-status]]).
- 신선도/주기는 텍스트(스크린리더 접근). 일시정지·새로고침 버튼은 키보드 조작·라벨·≥44px.

## 모션
- `prefers-reduced-motion`: 갱신 전환 애니메이션 0(즉시 교체). 스피너는 정적 대체 또는 최소.

## Grafana 임베드 — 갱신·테마 (노트, #2 불가침)
- **갱신:** Grafana kiosk가 자체 주기로 새로고침. 콘솔은 `var-instance`/`kiosk` URL만 관여([[tokens.spec]] §12). `buildEmbedSrc` 로직 변경 금지.
- **다크 테마 동기화(별도 게이트):** 콘솔 다크 시 임베드 URL `theme` 파라미터만 `dark`로 선택 동기화 가능 — **`var-instance`/`kiosk`/병합 규칙은 그대로**, `theme`만 토글. 기본은 `light` 유지(데이터·#2 회귀 0 우선). 구현은 이 패턴 채택 시 별도 진행.

## 상태 표기 토큰
- `live`: `success`/중립 점. `stale/지연`: `warning`(색+아이콘+"지연됨"). `paused`: `neutral`.

## Do / Don't
- **Do:** "마지막 갱신" 노출, polite 알림, 의미변화만 알림, 기존값 유지 갱신. **Don't:** assertive 남발, 매 틱 낭독, 갱신 중 화면 깜빡임, 오래된 값을 현재처럼.

## 검증
- 신선도 표기 존재(리뷰). aria-live politeness(보조기기/코드 점검). reduced-motion 무전환. 갱신 중 레이아웃 시프트 0(시각 QA).
