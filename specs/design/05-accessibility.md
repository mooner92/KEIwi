# 05 · 접근성 (WCAG 2.1 AA)

> 타협 불가 **통과 기준**. v3의 "색을 걷어낸다"는 방향은 접근성과 충돌하지 않는다 —
> 오히려 색 의존을 구조적으로 줄이므로 유리하다. 다만 **무채색이 늘어난 만큼 형태 부호화가 필수**가 된다.

---

## 1. 대비 하한선

| 대상 | 최소 | 근거 | v3에서 쓰는 토큰 |
|---|---|---|---|
| 본문 텍스트 | **4.5:1** | 1.4.3 | `ink`(17.76) · `ink-muted`(6.22) · `ink-subtle`(4.63) |
| 큰 텍스트(≥18.66px bold 또는 ≥24px) | 3:1 | 1.4.3 | — (v3는 큰 텍스트가 거의 없어 실질적으로 4.5:1 적용) |
| **UI 컴포넌트 경계·상태 그래픽** | **3:1** | **1.4.11** | `border-control`(3.20) · `accent-line`(3.45) · `danger`(4.83) |
| 장식 보더·구분선 | 없음 | 1.4.11 예외 | `border`(1.27) · `border-subtle`(1.15) |

### 절대 규칙 3가지
1. **`ink-faint`는 텍스트에 쓰지 않는다.**
   라이트 2.63:1 / 다크 2.68:1 — 어떤 배경에서도 AA 미달이다. 허용 용도는 **정상 dot · 구분자 · disabled
   아이콘**뿐. 메타 텍스트가 필요하면 `ink-subtle`(4.63:1)을 쓴다.
2. **`ink-subtle`을 `surface-2` 위에 놓지 않는다.**
   흰 배경 4.63:1 → 회색 면 위 **4.17:1로 미달**한다. 회색 면 위 보조 텍스트는 `ink-muted`(5.59:1).
3. **`warn`(#F79009)은 단독으로 정보를 전달하지 않는다.**
   흰 배경 **2.35:1** — 텍스트는 물론 비텍스트 3:1에도 못 미친다. 반드시 `warn-ink`(5.43:1) 텍스트나
   `warn-border` 보더를 동반한다.

### 다크 특례
- 텍스트 색은 순백 금지(할레이션). `ink #EDEEF1` = 15.33:1로 AAA 여유.
- **밝은 브랜드 면 위 흰 글자 금지**: `#FFF` on `#38B38D` = **2.62:1**.
  `accent-contrast`(#0C0D10, 7.40:1)를 쓴다.

## 2. 포커스 (상시 가시)

```css
:focus-visible {
  outline: 2px solid transparent;                  /* forced-colors 폴백 */
  outline-offset: 2px;
  box-shadow: 0 0 0 2px var(--color-surface),      /* 내부 밴드 */
             0 0 0 4px var(--color-accent-line);   /* 외부 링 */
  border-radius: var(--radius-sm);
}
```

- **더블 링인 이유는 장식이 아니라 대비 보장이다.** 내부 2px `surface` 밴드가 링의 판정 배경을 흰 면으로
  고정해 **3.45:1**을 보증한다. 밴드가 없으면 `surface-2` 위에서 3.10:1까지 떨어진다.
- **`accent`(원색)를 링에 쓰면 2.62:1로 1.4.11 위반.** 반드시 `accent-line`.
  (v2의 실제 결함 — [07](./07-changelog.md) 결함 ①)
- `outline: 2px solid transparent`는 **Windows 고대비 모드 폴백**이다. forced-colors에서 `box-shadow`는
  제거되지만 `outline`은 시스템 색으로 강제 렌더되므로 링이 살아남는다.
- **포커스 제거 금지.** `outline: none`만 쓴 컴포넌트는 리뷰에서 반려한다.
  컴포넌트가 개별 포커스 링을 만드는 것도 금지(전역 링과 겹쳐 두께가 흔들린다).
- `overflow:hidden`에 잘리는 자리는 inset 링:
  `box-shadow: inset 0 0 0 2px var(--color-accent-line); outline-offset: -4px;`

## 3. 색 단독 금지 · 색각 이상 대응

**WCAG 1.4.1** — 색은 정보 전달의 **유일한** 수단이 될 수 없다. v3는 여기서 한 걸음 더 간다:
**색 + 형태 + 단어 3중 부호화**([03 §0](./03-components.md)).

### 왜 형태가 필수인가
v3는 정상·여유·성공에서 유채색을 제거했다. 그 결과 **무채색 상태가 둘씩 생긴다**:
- 정상(●) 과 수집 없음(○) — 둘 다 `ink-faint`
- 여유(채운 면) 과 판정불가(점선) — 둘 다 무채색

색으로는 구분이 **불가능**하므로 형태가 유일한 시각 구분자다. 은유는 하나: **찼다 = 값이 있다 / 비었다 = 값이 없다.**

### 색각 이상 (약 8%의 남성)
- v3에는 **초록↔빨강 대비 조합이 존재하지 않는다.** 정상이 무채색이므로, 적록색약에게 가장 위험한
  "초록 점 vs 빨강 점" 상황이 구조적으로 발생하지 않는다.
- 유일하게 남은 유채색 쌍은 주황(`warn`) ↔ 빨강(`danger`)이며, 이 둘은 **배지 보더+배경+단어**로
  이미 3중 구분된다.

### 검증법
> **스크린샷을 흑백(그레이스케일)으로 변환한다. 정보가 하나도 사라지지 않아야 한다.**
> 사라지는 정보가 있으면 그 자리에 형태나 단어를 추가한다.

## 4. 키보드 · 시맨틱

- 모든 기능이 키보드만으로 도달·조작 가능. 논리적 tab 순서. `Enter`/`Space` 활성.
- **스킵 링크**: 첫 DOM 요소. `sr-only` → `focus-visible:not-sr-only`로 좌상단에 노출.
- 드로어/모달: 포커스 트랩 + `Esc` 닫기 + 닫을 때 **트리거로 포커스 복귀**.
- `aria-current="page"`(활성 내비) · `aria-selected`(활성 탭) · `role="tablist"/"tab"`.
- `disabled` 컨트롤은 `aria-disabled`를 함께 주고 이유를 라벨에 담는다
  (예: `aria-label="통합검색 (준비 중)"`).
- 장식 요소(dot·액센트 바·아이콘)는 `aria-hidden` — 정보는 옆의 단어가 전달한다.
- 표: `<caption>`(sr-only 가능) + `<th scope>`. 레이아웃용 표 금지.
- `.sr-only`: `position:absolute; width:1px; height:1px; margin:-1px; overflow:hidden; clip:rect(0,0,0,0); white-space:nowrap; border:0`.

## 5. 타이포 · 확대 · 모션

- 본문 **14px 하한**, 줄간격 **1.5**. UI 크롬 최소 11px(한글 자소 하한 — 10px에서 뭉갠다).
  v2의 17px에서 내렸지만 WCAG는 절대 px을 요구하지 않으며, 요구되는 것은 **줌 200% 지원**(1.4.4)이다.
- 200% 확대에서 레이아웃이 깨지지 않을 것. 텍스트 간격 조정(1.4.12)에도 잘림이 없을 것.
- **`prefers-reduced-motion: reduce`에서 모든 애니메이션·트랜지션 0.01ms**(전역 규칙).
  v3는 기본적으로 모션이 거의 없으므로(§00-5) 이 매체 질의가 바꿀 것도 적다 — 의도된 상태다.

## 6. 터치 타깃
- 터치 지원 기기에서 **≥44×44px**. 마우스 전용 관제 뷰는 밀도 우선(≥24px)이되,
  작은 컨트롤은 라벨 전체를 클릭 영역으로 확장한다.

## 7. 릴리스 체크리스트
- [ ] 키보드만으로 전 기능 도달, **포커스가 모든 단계에서 보임**(라이트·다크).
- [ ] 본문 4.5:1 / UI 경계 3:1 통과 — 특히 `surface-2` 위 텍스트를 별도 확인.
- [ ] `ink-faint`가 텍스트에 쓰이지 않았음(`grep`으로 확인 가능).
- [ ] 그레이스케일 스크린샷에서 모든 상태가 구분됨.
- [ ] 폼 오류가 색 + 텍스트 + 보더로 표시됨.
- [ ] 표에 caption/`th scope`, 이미지에 alt, 장식 요소에 `aria-hidden`.
- [ ] reduced-motion에서 애니메이션 없음.
- [ ] forced-colors(Windows 고대비)에서 포커스 링이 보임.
