# 04 · 패턴 (페이지 · 임베드 · 상태 · 밀도)

> 컴포넌트를 **조합**하는 규칙. v3의 핵심 차별점인 **외부 임베드 액자화**가 여기 있다.

---

## 1. 페이지 골격

```
[스킵 링크 — 첫 DOM]
[상단바 56px : 로고 · 서비스명 · 환경 라벨 | 검색 · 테마 · 유틸]
┌────────────┬──────────────────────────────────────────┐
│ 사이드바    │ 메인 (p-4 / sm:px-6, 자체 스크롤)          │
│ 224px      │   breadcrumb (11~12px, ink-subtle)        │
│            │   H1 20px semibold  [우측 액션 슬롯]        │
│            │   ── 주 콘텐츠 (뷰포트의 ≥60%) ──          │
│            │   보조 섹션                                │
└────────────┴──────────────────────────────────────────┘
```
- **크롬은 그림자 0**, 분리는 `border-b` / `border-r` 1px.
- 세로 리듬: breadcrumb→H1 **4px**, H1→콘텐츠 **16px**, 섹션 간 **16px**. (v2의 32~80px 리듬 폐기)
- 데스크톱/랩톱(1440·1366)에서 **세로 스크롤 없음**이 기본 목표다. 모바일만 스크롤 허용.
- 풀폭 사용. `max-w-1200` 같은 콘텐츠 폭 제한은 문서형 페이지(`/about`)에만.

### 페이지 헤더
- H1 = `text-xl`(20px) `font-semibold` `text-ink`. 설명은 13px `ink-muted` 한 줄.
- 액션은 헤더 우측 슬롯에 `sm` 버튼으로. **primary는 최대 1개.**
- 내용이 자명한 섹션(임베드 영역 등)은 시각 헤더를 생략하되 `aria-label`/sr-only 헤딩으로
  **시맨틱은 남긴다.** 시맨틱까지 없애는 것은 불가.

## 2. 외부 임베드 "액자화" — v3의 핵심 패턴

> **문제.** 화면의 약 2/3이 우리가 스타일을 통제할 수 없는 iframe(Grafana)이다.
> 콘솔이 자기 색·그림자·모션을 쓰면 두 디자인 언어가 경계에서 충돌해 "덧댄 UI"가 된다.
>
> **해법.** 콘솔을 **액자**로 만든다. 액자는 그림을 방해하지 않고 벽에서 그림을 분리만 한다.

### 액자 규격
| 항목 | 값 | 이유 |
|---|---|---|
| 컨테이너 | `rounded-lg border border-border bg-surface` | 카드와 **동일 규격** — 임베드도 이 시스템의 한 요소다 |
| 그림자 | **0** | §00-4. 액자는 떠 있지 않다 |
| 내부 여백 | **0** | iframe이 자기 패딩을 갖는다. 이중 여백 금지 |
| 최소 높이 | 240px | 그 이하는 Grafana가 축 라벨을 못 그린다 |
| 채움 | `flex-1` + `min-h-0` | 남는 세로를 전부 먹는다(콘텐츠 우선) |
| `loading` | `lazy` | 탭 전환 전 대시보드는 로드하지 않는다 |

### 색온도 정합 (수치)
액자가 어긋나 보이지 않으려면 **면 명도가 Grafana와 같은 계단에 있어야** 한다.

| | 우리 | Grafana | 대비 |
|---|---|---|---|
| 라이트 canvas | `#F7F8FA` | `#F4F5F5` | 1.03:1 — 사실상 같은 종이 |
| 라이트 패널/카드 | `#FFFFFF` | `#FFFFFF` | 동일 |
| 다크 canvas | `#0C0D10` | `#111217` | 1.04:1 — **우리가 한 단 어둡다** |
| 다크 패널/카드 | `#16181B` | `#181B1F` | 1.03:1 — 같은 레벨 |

- 라이트에서는 두 세계가 **한 장의 종이 위**에 놓인다.
- 다크에서는 부호가 뒤집혀 **임베드가 살짝 떠오른 면**이 된다(그림자 없이 명도만으로).
- 뉴트럴 hue를 220 근처 쿨로 잡은 것도 이 정합 때문이다. 웜그레이 크롬 + 쿨 Grafana는 경계에서
  색온도가 어긋나 즉시 이질감을 준다.

### 테마 동기화 (필수)
콘솔 테마가 바뀌면 **iframe `src`의 `theme=` 파라미터도 함께** 바뀌어야 한다.
콘솔만 다크로 가고 임베드가 라이트로 남으면 화면 한가운데 흰 판이 뜬다 — 침묵 원칙의 최악 위반.
- `kiosk` 파라미터로 Grafana 자체 크롬(헤더·내비)을 숨긴다. **크롬은 하나면 충분하다.**
- 기존 쿼리(`var-*`, `from/to`, `refresh`)는 보존하고 `kiosk`/`theme`만 갱신한다.

### 액자 주변의 크롬
- 탭바는 액자 **위**에 붙되 자체 배경 없이 `border-b`만(→ [03 Tab](./03-components.md)).
- "새 탭에서 열기 ↗"는 별도 행을 만들지 말고 **탭 행 우측으로 흡수**한다(세로 공간 절약).
  링크는 `text-xs text-ink-muted underline underline-offset-2`.
- 임베드 범위를 오해할 여지가 있으면(예: 노드 선택과 무관한 전역 뷰) 액자 위에
  1행 안내 배너: `rounded-md border border-border bg-surface-2 px-3 py-1 text-xs text-ink-muted`.
  **경고색을 쓰지 않는다** — 문제가 아니라 사실 설명이다.

### 임베드 미연결/실패
`rounded-lg border-dashed border-border-strong bg-surface-2` 점선 액자 + 제목 13px `ink` +
설명 13px `ink-muted`(설정해야 할 환경변수명은 `.tnum`으로 표기). 점선 = "아직 비었다"(§03-0의 형태 은유).

## 3. 상태 표현 패턴

- **정직성 3분법**: `정상(up)` ≠ `장애(down)` ≠ `수집 없음(no-data)`. 셋을 색·형태·단어로 모두 구분한다
  (→ [03 §0](./03-components.md)). 불확실은 "판정불가"로 표기하고 절대 "정상"으로 접지 않는다.
- **요약 카운트**("12 정상 · 1 다운 · 2 수집 없음"): 숫자는 `.tnum`, 정상 카운트는 **무채색**,
  다운만 `danger-ink`. 0인 항목은 회색으로 남기되 지우지 않는다(항목이 사라지면 위치가 흔들린다).
- **배경 워시로 상태를 표현하지 않는다.** 카드 전체를 붉게 칠하면 다크에서 탁해지고 텍스트 대비가 깨진다.
  대신 **좌측 4px 액센트 바 + 상태 배지**.
- **깜빡임·펄스 금지.** 새 장애는 목록 최상단 위치와 타임스탬프로 알린다(§00-5).

## 4. 밀도 리듬 — 3단계면 충분하다

| 간격 | 값 | 쓰는 곳 |
|---|---|---|
| **조임** | 2~8px | 단일행 크롬 내부: 내비 항목 간, 배지 사이, dot↔라벨, 표 행 패딩 |
| **묶음** | 12px | 같은 블록 안의 그룹 분리: 카드 그리드 갭, 패널 내부 섹션 |
| **분리** | 16px | 의미 블록 사이: 섹션 간, H1↔콘텐츠 |

- 24px 이상의 여백은 **빈 상태·문서형 페이지에만**. 관제 화면에 24px 여백이 보이면 대개 설계 실수다.
- **크롬을 줄여 콘텐츠를 늘린다.** 주 콘텐츠가 뷰포트의 60%에 못 미치면:
  ① 섹션 헤더 생략(시맨틱만 유지) ② 스트립 슬림화 ③ 안내행을 탭 행으로 흡수 ④ 부가 정보를 `title` 툴팁으로.
  **콘텐츠를 줄여 크롬을 살리지 않는다.**

## 5. 페이지 유형별

- **관제(Overview·Logs)**: 헤더 최소 → 필터/노드 스트립 → 액자. 스크롤 없이 한 화면.
- **목록**: 표([03 §7]) 우선. 필터 칩은 표 위 한 줄. 빈 상태 명시.
- **워크벤치(임베드 + 보조 패널)**: 좌우 또는 상하 분할. 보조 패널도 그림자 0 카드 규격.
  **분할 비율은 임베드 우선**(최소 1:1, 기본은 임베드가 더 큼).
- **문서형(`/about`)**: 여기서만 `max-w-3xl` 읽기 폭 + 24px 리듬 + `text-md` 본문을 허용한다.
  관제 밀도 규칙은 관제 화면의 규칙이지 모든 화면의 규칙이 아니다.

## 6. 채택하지 않는 것
- **정부 마스트헤드/기관 식별자** — 내부 콘솔에 붙이면 허위 표기다. (v2에서 이미 미채택)
- **네이티브 시계열 차트** — Grafana 임베드 유지(헌장 §2 / ADR-0002).
- **토스트 알림** — 관제 화면에서 사라지는 알림은 놓친 알림이다. 상태는 화면에 상주시킨다.
