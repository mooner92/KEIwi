# 04 · 패턴 (페이지·상태·크롬)

> 컴포넌트를 조합하는 페이지 레벨 규칙. KRDS 서비스 패턴/기본 패턴 + 관제 콘솔 보정.

## 페이지 골격
```
[스킵 링크(첫 DOM)]
[헤더: 로고(좌상단) · 유틸 · (검색) · GNB]
[사이드 내비(LNB)]  [메인:
                      breadcrumb
                      H1 (페이지 제목, 32px)
                      섹션(H2 19px) …
                    ]
[푸터: 서비스 로고 · (정부 식별자) · 링크]
```
- 리듬: breadcrumb→H1 24~32 · 섹션 간 24~32 · 콘텐츠→푸터 여유. 컨테이너 max 1200/wrap 1248, 화면 여백 24(관제 풀폭은 예외 허용).
- 위계: H1 32(heading-large) · 섹션 H2 19(heading-small) · 카드 제목 17 bold · 본문 17.

## 기본 페이지 패턴(KRDS 기본 패턴 12종 중 콘솔 핵심)
- **목록(list)**: 표([03] Table 규격) 또는 카드 그리드. 필터/정렬 컨트롤 상단. 빈 상태 명시.
- **상세(detail)**: 요약 → 상세 필드(구조화 목록) → 관련 액션.
- **입력폼(form)**: 라벨 필수·헬퍼·인라인 검증(색+텍스트+2px 보더). 파괴적 동작은 확인(모달).
- **필터·정렬**: 태그/셀렉트. 적용 상태 가시화.
- **오류(error)**: 무엇이·왜·**어떻게 복구**하는지 안내(단순 통보 금지). danger 배너 + 조치.
- **피드백**: 전환형=Toast/Snackbar · 지속형/긴급=Critical alerts(긴급 공지) · 장시간 작업=Step indicator+Spinner.

## 상태 표현 (관제 콘솔 핵심)
- 노드/서비스/작업 상태 = **StatusPill**(dot+라벨, [03]). 색 계열: success/danger/warning/neutral.
- **정직성 3분법**: `정상(up)` ≠ `장애(down)` ≠ `데이터 없음(no-data)`. 데이터 없음/불확실을 "정상"으로 오인시키지 않는다("판정불가" 사용).
- 요약 카운트(예: "N 정상 · M 다운 · K 데이터 없음")는 각 숫자에 상태색 텍스트.
- 카드 좌측 상태 액센트 바(4px) + StatusPill 병행. 상태를 배경 워시로만 표현하지 않는다(다크에서 탁해짐).

## 빈 상태 / 준비중
- 중앙 정렬 카드: (선택)마일스톤 배지 + 제목(24) + 설명(15) + (선택)액션. 회색 톤·과한 일러스트 지양.
- 외부 임베드(iframe 등)가 인증/네트워크로 빌 수 있으면 "새 탭에서 열기 — 인증 필요할 수 있음" 링크 제공.

## 정부 크롬 (⚠️ 조건부)
KRDS 정부 사이트 필수 요소 — **공식 전자정부 서비스에만** 적용:
- **마스트헤드(공식 배너)**: 최상단 고정, 텍스트 "이 누리집은 대한민국 공식 전자정부 누리집입니다"(수정 불가). **비-정부 사이트엔 금지.**
- **스킵 링크**: 마스트헤드보다도 앞선 **첫 DOM 요소**(z 10000, focus 시 표시).
- **운영기관 식별자**: 기관 로고 + "운영기관: [기관]" — **푸터 안**(헤더 아님). 서비스 로고와 구분.
- **헤더 순서**: 스킵 → 서비스 로고(좌상단) → 유틸(우상단, ≥5개면 드롭다운) → 검색 → GNB → 아이콘버튼(텍스트 라벨 동반).

> **내부 운영/관제 콘솔 판단**: 공식 전자정부 마스트헤드/식별자는 **허위 표기**가 되므로 넣지 않는다. 대신 **스킵 링크(필수)·자체 식별 스트립("관제 콘솔"·환경 표시)·헤더 순서·컴포넌트 규격**만 채택한다. (KEIwi 적용 방식 — [07](./07-changelog.md))
