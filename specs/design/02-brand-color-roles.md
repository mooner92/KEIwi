# 02 · 브랜드 색 & 색 역할

> **핵심 규칙: 브랜드 색·로고는 프로젝트 자체 것.** KRDS 정부 블루(#256ef4)·KRDS 로고를 그대로 쓰지 않는다. KRDS의 뉴트럴·시맨틱·컴포넌트 규격만 채택하고, **primary(브랜드)만 교체**한다.

## 왜 브랜드만 교체하나
KRDS 원본은 브랜드가 3계열로 묶여 컴포넌트에 스며 있다:
- **primary(정부 블루 #256ef4)** — 주요 액션·활성·링크·입력 활성 보더·**포커스 링**.
- **secondary(네이비 #346fb2)** — 탭/브레드크럼/페이지네이션/표 헤더의 tint, 아코디언 open.
- **point(레드 #d63d4a)** — 알림/포인트(사용 ≤5%).

→ 자체 컴포넌트를 만드는 프로젝트는 KRDS의 `.krds-*` 클래스 대신 **시맨틱 토큰만** 쓰므로, 실무적으로 **`--color-brand`(+ 포커스 링) 하나만** 자기 브랜드로 바꾸면 된다. secondary/point까지 쓰는 경우만 추가 교체.

## 색 역할 체계 (구현 시 이 역할로만 참조)
| 역할 토큰 | 의미 | 소스 |
|---|---|---|
| `brand` / `brand-strong` | 정체성·1차 액션·활성 내비·선택·포커스 | **자체 브랜드** |
| `info` | 정보성·텍스트 하이퍼링크 | KRDS information(블루) |
| `success` | 정상/긍정 상태 | KRDS success |
| `warning` | 주의(채움=밝은 30, 텍스트=어두운 50/60) | KRDS warning |
| `danger` | 오류/장애 | KRDS danger |
| `neutral` / gray 램프 | 크롬·텍스트·보더·면 | KRDS gray |

### 색 역할 분리 (중요)
- **brand ≠ success.** 브랜드가 초록 계열이면 상태 success(초록)와 **색 계열을 분리**하라(예: 브랜드=teal, success=forest). 안 그러면 "브랜드 액센트"와 "정상 상태"가 헷갈린다.
- **링크는 info(블루)** 유지 권장 — 브랜드가 강한 색일 때 화면이 한 색으로 덮이는 것을 막고, "클릭 가능"의 관습(파란 링크)을 살린다.
- **상태색은 상태 전용.** success/warning/danger를 장식·브랜딩에 쓰지 않는다.

## 자체 브랜드 램프 채우는 법
9~10 step(50~900 또는 5~95) 램프를 만들고 500(또는 50)을 base로. 최소 필요:
- `brand` = base(대비 ≥3:1 대 흰 배경 — 라이트에서 포커스 링/텍스트로 쓰이므로), `brand-strong` = +1 step(hover/pressed).
- 다크(고대비)에서는 **밝은 step**을 brand로(근흑 면 대비). 예: 라이트 brand=500, 다크 brand=300.
- 브랜드 base가 흰 배경에서 대비 부족(예: 밝은 teal)하면 포커스 링·텍스트엔 +1 step을 쓰거나 더블 링(면 분리 2px)으로 가시성 확보.

## 참조 구현 — KEIwi 브랜드 (예시)
정체성 = 초록(primary) + 블루(secondary). ADR-0007. **다른 프로젝트는 이 두 램프만 자기 것으로 교체하면 됨.**

**KEIwi 매핑**
- 라이트 `--color-brand = green-500` · `--color-brand-strong = green-600`
- 다크 `--color-brand = green-300` · `--color-brand-strong = green-200`
- 포커스 링 = `--color-brand`(더블 링) → 초록 자동.
- 링크·정보 = `info`(KRDS 블루). 상태 = success/warning/danger.
- 로고 = 자체 brand-mark(초록/블루 스플릿) — 변경 금지.

> KEIwi 이력: 2025-06 "표준형" 전환 때 `--color-brand`를 KRDS 정부 블루로 바꿨다가, 2026-07-01 사용자 지시로 **자체 초록으로 원복**. 교훈 = "브랜드는 자체 것" 규칙을 어기면 정체성이 흔들린다.
