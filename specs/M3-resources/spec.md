## 목적

플릿(data01~05)에서 **"지금 어느 서버가 여유 있는지" 한눈에 보고 작업(특히 GPU 작업)을 배치**하게 한다.

- M1(메트릭)이 **"노드별 상세 상태"**(CPU/메모리/GPU 그래프)를 보여준다면, 여유 리소스 뷰는 그 위의 **"판정·배치 결정" 레이어** — 운영자/연구자가 ssh로 일일이 `nvidia-smi`/`htop` 안 쳐보고 콘솔에서 바로 "data0X가 비었다 → 거기 돌려라"를 안다.
- **WHY — 제품 비전(README §3).** KEIwi의 목적 자체가 *"어느 서버가 여유 있는지 파악해 작업 배치를 돕는다"*. 이 뷰가 그 비전의 1차 실현.
- **WHY — 공용 서버 경합 해소.** 여러 연구자가 같은 GPU 서버에 몰리면 OOM·경합. "여유 서버"를 먼저 보면 충돌을 피한다.
- **WHY — M1 재사용(헌장 §6 지루한 기술).** 새 exporter·수집 없이 이미 모으는 node-exporter·DCGM 메트릭에서 **판정만 파생**.
- **WHY — 단일 콘솔(헌장 §I-2).** 이 뷰는 fleet strip 같은 **네이티브 "결정 보조" 뷰**이지 메트릭 대시보드 재구현이 아니다 — 상세 수치는 기존 Grafana 임베드로 드릴다운.

성공은 §수용 기준의 기계 검증으로 정의한다(헌장 §9).

## 범위 (in / out)

### In
1. **노드별 여유 판정** — 각 노드를 사용률 메트릭으로 평가해 **여유도**를 표시한다. 핵심 축:
   - **GPU 여유**(GPU 보유 노드): GPU 사용률(util) + 가용 VRAM. "지금 GPU 작업 받을 수 있나".
   - **일반 여유**: CPU 여유 + 가용 메모리. "일반 연산·jupyter·웹 받을 수 있나".
2. **여유 순위·배치 추천** — 여유한 순으로 정렬하고, **"지금 GPU 작업은 data0X"** 같은 한 줄 추천을 보여준다.
3. **Overview 통합** — 별도 Resources 탭이 아니라 **Overview 화면에 여유 리소스 섹션**을 둔다(ADR-0012). 기존 플릿 strip과 일관.
4. **드릴다운 재사용** — 여유 카드/행을 누르면 그 노드의 상세 메트릭(기존 Overview의 Grafana 임베드)으로 이동.
5. **정직한 판정** — 메트릭이 없는 노드(no-data, GPU 없음 등)는 **"판정 불가/해당 없음"**으로 표기(추정으로 "여유"라 하지 않음 — M1 US4 정신).

### Out
- **자동 배치·스케줄링**(작업을 실제로 노드에 띄우는 것) — 비전(장기), 이번 범위 아님.
- **메트릭 대시보드 재구현** — 상세 그래프는 Grafana(§I-2). 이 뷰는 판정·요약만.
- **예약·쿼터·멀티테넌시**(누가 얼마나 쓸지 관리) — 범위 밖.
- **알림**(여유 변화 통보) — M5.
- data01~03은 **접근·메트릭 준비된 노드부터**(M1·M2와 동일 — data04·05 우선).

## 사용자 스토리

운영자·연구자 관점.

- **UR1 — 여유 서버 한눈에.** "지금 GPU 작업 돌릴 여유 있는 서버가 어디지?"를 콘솔 한 화면에서 보고 싶다(ssh·nvidia-smi 없이).
- **UR2 — 배치 추천.** 여유한 순으로 정렬되고 "여기 돌려라"를 추천받고 싶다.
- **UR3 — 근거 확인(드릴다운).** 추천을 믿기 전에 그 노드의 실제 메트릭(GPU util·VRAM·CPU·메모리)을 바로 확인하고 싶다(Grafana).
- **UR4 — 판정 기준 이해.** "여유"가 무슨 기준(임계)인지 알고 싶다(과신 방지).
- **UR5 — 정직한 판정.** 데이터 없는/GPU 없는 노드를 "여유"로 오인하지 않게, "판정 불가/해당 없음"으로 보고 싶다.

## 수용 기준 (기계 검증 가능)

- [ ] 각 대상 노드의 **여유 판정**(예: GPU 여유 / 일반 여유 / 바쁨 / 가득 / 판정불가)이 Prometheus 메트릭 기반으로 표시된다.
- [ ] **GPU 보유 노드**는 GPU 사용률·가용 VRAM 기준으로, 그 외는 CPU·메모리 기준으로 판정된다(노드 특성 반영).
- [ ] **여유 순위**가 표시되고, GPU 작업 배치 **추천 노드**가 제시된다.
- [ ] 메트릭 없는 노드(no-data)·GPU 없는 노드는 **"판정 불가/해당 없음"**(거짓 "여유" 금지).
- [ ] 여유 카드/행 → 그 노드 **상세 메트릭(Grafana 드릴다운)**으로 이동(기존 재사용).
- [ ] **판정 임계가 문서/툴팁으로 노출**(UR4) — 사용자가 기준을 안다.
- [ ] 단일 콘솔(§I-2) 준수 — 상세 그래프는 Grafana, 이 뷰는 판정·요약(대시보드 재구현 아님).
- [ ] 콘솔은 Prometheus를 **읽기만**. 시크릿 레포 밖(§13). Prometheus 불가 시 안전 귀결(전부 판정불가, 절대 거짓 "여유" 아님).
