# 0014. 온프레미스 로그 어시스턴트 — 아키텍처·범위 결정

- 상태: 채택 (2026-06-29)
- 관련: [spec](../../specs/assistant/spec.md) · [plan](../../specs/assistant/plan.md) · [ADR-0012](0012-roadmap-m3-m4-pivot.md)(M4/M5 흡수) · [ADR-0011](0011-signal-first-log-ux.md)(베이스라인).
- 근거: 설계 워크플로(2026-06-29, 6에이전트) 비평이 검증·축소한 결과.

## 맥락

운영자가 에러를 만났을 때 로컬 LLM이 로그를 근거로 진단해 주길 원한다(사용자 시나리오: 에러→질의→근거확보→해결→리포트→지식화). 자체 GPU에 vLLM이 이미 떠 있어 온프레미스 RAG가 가능. 그러나 5서버 규모에 LLM 레이어를 얹는 것은 과설계·환각·GPU 경합 위험이 크고, **이미 강력한 신호 우선 /logs 대시보드(ADR-0011)가 베이스라인**이다.

## 결정

1. **로컬 vLLM + OpenSearch + 무의존성 BFF.** 추론=로컬 vLLM(`172.18.0.1:8003`, OpenAI 호환), 검색=OpenSearch BM25, 묶음=Next.js server-only route(`fetch`만, LangChain/SDK/벡터DB 없음). 외부 egress 0. 기존 `lib/prometheus.ts` read 패턴 동형.
2. **읽기 전용 · 자동적용 영구 보류.** 어시스턴트는 검색·요약·**기존 런북 링크**까지만. fix 자동 생성 안 함(로그엔 해결책이 없어 환각 최고 위험). 조치 적용은 사람 PR 게이트(§11/§15) — **자동적용은 강한 정당화 없이는 영구 보류**.
3. **인용 = 서버 제공 번호 근거.** 모델이 doc _id를 만들지 않는다. 서버가 검색셋에 [1][2]… 번호를 붙이고 UI는 서버의 실제 로그를 렌더 → 날조 인용 불가(수용기준).
4. **벡터/임베딩·관계형 인시던트DB 도입 안 함(measure-first).** 코퍼스 N≈1(런북 1건). keyword(service·category·메시지 시그니처)+BM25로 시작. 키워드 부족이 입증된 뒤에만 ADR로 임베딩(로컬, 외부 금지).
5. **KB = 레포 마크다운 런북(SoT) + 파생 인덱스.** 런북이 진실의 원천(사람 PR 머지=적용 게이트, §10/§11). 파생 검색 인덱스는 git HEAD 머지본에서만 재빌드(draft 인덱싱 금지 — 미검증 LLM 본문의 복리 오염 방지). 파생 인덱스는 **keiwi-logs ISM 밖**(365일 delete가 KB를 지우는 함정 회피).
6. **거주지 = 보류 `/incidents`(M4) 탭 전용.** 새 탭 난립 없이 합법적 커스텀 뷰. M4/M5를 이 어시스턴트로 경량 흡수(정식 incident board·능동알림 안 만듦).
7. **GPU 자기경합 정책: on-demand·레이트리밋.** 백그라운드 폴링 없음, 클릭 시에만 vLLM 호출, 동시 1요청. busy 시 큐잉/지연 UX. (B 대시보드가 "어시스턴트가 GPU 먹는 중"을 표시하는 역설 인지.)
8. **가치 수용기준 필수.** "사람이 그냥 /logs Grafana 본다" 대비 더 빠르고 신뢰됨을 측정 — 배관(N초내 응답)이 아니라 가치. 못 이기면 출시 보류.

## 고려한 대안

- **tool-calling 에이전트**(LLM이 OpenSearch/Prometheus를 도구로 호출) — 비결정성·통제난이. 5서버엔 고정 RAG가 단순·통제 가능 → 기각(연기).
- **벡터DB/임베딩 RAG** — N≈1 코퍼스에 의존성·운영비만 추가, §6 위배 → 컷(입증 후).
- **관계형 인시던트DB(SQLite/Postgres)** — frontmatter+git+detection_query 집계로 충분, ADR-0012("5서버엔 과설계") 정합 → 보류.
- **fix 생성·자동적용·능동알림** — 환각·운영 위험·§11/§15 → 컷/영구보류.
- **외부 LLM API** — §I-1 온프레미스·데이터 유출 → 금지.

## 결과

- 콘솔에서 에러→근거 진단→런북 연결이 외부 egress 0으로 동작. M4/M5를 무겁지 않게 흡수.
- 산출물: `apps/console`(env·lib/opensearch·lib/vllm·lib/assistant·/api/assistant·현재신호 뷰·어시스턴트 탭), 런북 frontmatter 표준.
- 가장 큰 리스크 관리: 환각(인용 서버검증·fix 미생성), 경합(on-demand), 가치(베이스라인 수용기준), 인젝션·시크릿(격리·스크럽).
