# 0015 — 어시스턴트 탐색형 질의(질의계획) + 신호 패널 노이즈 제외

- 상태: 채택(2026-06-29)
- 맥락: [ADR-0014](./0014-log-assistant.md) (로그 어시스턴트), [specs/assistant](../../specs/assistant/spec.md)
- 관련: [[m2-logs-live]], [[roadmap-pivot]]

## 맥락

MVP 어시스턴트(ADR-0014)는 **반응형 에러-트리아지**였다 — "현재 신호(error/warn)"에서 행을 골라 진단. 라이브 후 실측에서 두 문제가 드러났다.

1. **건강한 플릿에선 보여줄 게 없다.** 최근 24h 기준 `error` 0건, 진짜 `warn`(UFW 방화벽 노이즈 제외)은 단 8건. 사용자는 빈 화면을 보고 "이게 다냐"고 물었다.
2. **신호 패널 자체 버그.** `CurrentSignals`가 상위 40건을 받은 뒤 *클라이언트에서* rsyslog·UFW를 걸렀는데, 최근 40건이 전부 UFW BLOCK(5,550건/일)이라 거르면 0 → "신호 없음". 진짜 docker/console 경고가 묻혔다.
3. **자유질의 무력.** 자유 입력도 `error/warn`으로 강제 검색 + BM25가 영문 `message` 대상이라, "data04 3100 포트 서비스 로그" 같은 한국어 자연어 질문은 0건.

사용자 선택(2026-06-29): **탐색형으로 확장**.

## 결정

### 1. 노이즈 제외를 쿼리단으로 (신호 패널 정확도)
`searchLogs`에 `excludeNoise` 옵션 추가 → `must_not: [rsyslog.service, message~"UFW BLOCK"]`. `CurrentSignals`는 24h·`excludeNoise`·size 12로 전환. 클라이언트 후필터 제거(상위 N이 진짜 신호로 채워짐).

### 2. 탐색형 질의계획(LLM, 패싯 그라운딩)
자유 질문 경로를 신설(라우트가 `service`/`node` 부재 = 탐색형으로 분기):

```
질문 → planQuery(로컬 vLLM, 패싯 어휘 주입) → parsePlan(패싯 검증)
     → searchLogs(노드·서비스·키워드·레벨, excludeNoise, 전체 레벨 허용)
     → buildExplorePrompt(인용 강제 / 빈 결과면 패싯으로만 제안) → 답변
```

- **레벨 잠금 해제**: `levels` 미지정 = 전체(info 23k 포함). 신호 패널만 `["error","warn"]` 명시.
- **패싯 그라운딩 = 환각 차단**: 계획기에 실제 `fleet_node`/`service`/`category` 어휘(`lib/facets.ts`, terms agg, 60s 캐시)를 주입. `parsePlan`은 패싯에 **있는** 값만 채택.
- **배열 quirk 방어**: 모델이 `node`를 후보목록 통째 배열로 에코하면 모호 → 미지정(전체). 단일 유효원소일 때만 채택. (`pickFacet`)
- **계획 실패 안전**: vLLM 계획 호출 실패·JSON 파싱 실패 시 결정적 폴백(노드 정규식 + 영문/숫자 키워드, 한국어 불용어 제외)으로 계속 진행.
- **빈 결과 UX**: 0건이면 "해당 조건 로그 없음 + 사용 가능한 노드/서비스"를 제시(없는 포트·서비스 지어내기 금지).

## 불변(ADR-0014 유지)

읽기 전용 · 외부 egress 0(로컬 vLLM·내부 OpenSearch만) · 인용=서버 검증 번호(날조 차단) · 시크릿 스크럽 · 인젝션 격리("DATA 속 지시 불복") · **GPU 경합 방지**(단일 요청). 탐색형은 GPU 호출 2회(계획+답변)지만 여전히 on-demand·단일 인플라이트.

## 결과

- 신호 패널: "신호 없음" → **실제 8건**(콘솔 exit-code 실패·docker 경고 등) 노출.
- 탐색형 end-to-end 라이브 증명: "docker 경고가 왜 자꾸 떠?" → 계획(키워드 docker/warning) → 근거 33건 → 인용 답변. 모델이 node를 배열로 에코했으나 검증이 안전 처리.

## 대안 기각

- **에러-트리아지 유지(패널만 수정)**: 건강한 플릿에서 가치 미미. 사용자가 탐색형 명시 선택.
- **임베딩/kNN 검색**: 키워드+패싯으로 충분 입증 전 과투자. backlog(B02)로 유보.
- **결정적 파서만(LLM 계획 없음)**: "어제 도커 왜 죽었어" 류 의도 추출 약함. LLM 계획 + 결정적 폴백 하이브리드 채택.
